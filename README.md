# MarveThabi Consulting Engineers

Production web application migrated from the custom WordPress theme to a modern, fast React + TypeScript + Vite architecture.

## Overview
MarveThabi Consulting Engineers is a multidisciplinary South African engineering consultancy delivering specialist Reliability Engineering, Asset Management, Electrical Engineering, and Geo-Environmental solutions for government, municipalities, mining, energy, and industrial sectors.

## Features
- **Original Brand Styling & Design**: Exact preservation of the custom Geist and Fira Sans typography, design system, colors, rhythm, animations, and layouts.
- **Home View**:
  - Technical blueprint hero section with animated circuit grid, pulsing nodes, and real-time project statistics.
  - Trusted client credentials marquee track.
  - Company overview, multidisciplinary story, and professional registration badges (ECSA, SACNASP, ISO55000, CIDB).
  - Four engineering services discipline overview cards.
  - Industries served and competitive differentiators.
  - Live animated statistics counter on viewport entry.
  - Professional leadership qualifications cards with hover reveals.
  - Six-step engineering process roadmap.
  - Interactive featured capabilities rotator with tabbed switching and FIG technical numbering.
  - Interactive consultation request form with validation and instant feedback.
- **Services Catalogue (`/services`)**:
  - Self-drafting CAD plotter hero with SVG vector layers, animated crosshair cursor, snapping pulses, live HUD coordinates, and approval stamp.
  - Scroll-spy interactive directory navigation.
  - Complete 12 service lines organized across 3 groups (Engineering Services, Environmental Resource Management, Specialist Studies) with radar scanline media, technical deliverables, and specifications.
  - Statutory professional affiliations (ECSA, SAIEE, SACNASP).

## Tech Stack
- **Framework**: React 18 + TypeScript + Vite
- **Styling**: MarveThabi Design System (`/assets/css/main.css`)
- **Port**: 3000 (`0.0.0.0`)

## Development
```bash
npm run dev     # Starts the Vite dev server on port 3000
npm run build   # Type-checks and builds the production bundle
npm run lint    # Runs TypeScript compiler check
```
