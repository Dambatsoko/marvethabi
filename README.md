# MarveThabi

Existing custom WordPress theme being migrated to React.

## Important
This repository contains only the custom `marvethabi` theme, not WordPress core.

Primary design/template files:
- `front-page.php`
- `page-services.php`
- `header.php`
- `footer.php`
- `functions.php`
- `assets/css/main.css`
- `assets/js/main.js`

The goal of the next phase is to migrate the existing design and functionality to React without redesigning it.
